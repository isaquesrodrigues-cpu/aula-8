
Seção 6 — Critérios de "pronto"

Definam, em formato de checklist, o que o grupo considera que uma tela está pronta para ser fechada. Esse será o padrão de qualidade aplicado a todas as telas.

 

Exemplos do tipo de critério esperado:

[ ] HTML semântico (uso correto de header, main, section, footer)

[ ] CSS sem style="..." inline

[ ] Funciona em mobile (largura 390px) sem elementos cortados

[ ] Funciona em desktop (largura 1440px)

[ ] Não há erros no console do navegador

[ ] Links e botões levam para a tela correta (mesmo que ainda não funcional)

[ ] Padrão visual (cores, tipografia, espaçamento) consistente com o mockup

[ ] Código revisado por pelo menos um outro integrante do grupo

[ ] Commit feito com mensagem descritiva

 

O grupo pode adicionar ou ajustar os itens — mas a lista final deve ter no mínimo 8 critérios.
